## Итог по этапу 1 (маршруты и SEO) — что проверено и в порядке

- `/ka`, `/en`, `/ru` без слеша → 200 на `/ka/`, `/en/`, `/ru/`; `/index.html` → `/`; `/ru/index.html` → `/ru/`.
- `http://monocapitals.ge/ru` → `https://www.monocapitals.ge/ru/` (HTTPS и www работают).
- DNS полностью на Vercel (NS `ns1/ns2.vercel-dns.com`), почта Google (MX) сохранена, записей Wix не осталось.
- Все 42 URL, которые Google держит в индексе, и все 49 адресов из списка старого сайта отдают новый сайт: 96 вариантов (со слэшем и без), ошибок 0. Редиректы постоянные (`permanent: true`, у Vercel это 308).
- **«/ru и /en отдают старый сайт» — не воспроизводится.** `/ru` и `/en` отдают новую версию (`lang`, title, canonical верные). Старый вид может показываться только в выдаче Google, пока он не пересканировал страницы; 8.10 запрошена переиндексация `/ka/`, `/en/`, `/ru/`.
- Несуществующий URL → 404 с noindex; `/api/lead` GET → 405; `robots.txt` и `sitemap.xml` → 200, sitemap содержит 7 URL с hreflang.
- title, description, один H1, Open Graph, `twitter:card`, hreflang ka/en/ru/x-default, язык страницы совпадает с содержимым на всех трёх версиях.

## Функциональные проверки (этап 2) — результат

`tools/audit-functional.mjs`: **до — 111 из 119, после — 120 из 120** (добавлена проверка полноэкранного просмотра). Две из восьми ошибок «до» были ошибками самого теста (неверный путь к PDF; фокус на скрытой радиокнопке, рамка которой показывается на подписи). Их исправил в тесте, на сайте ошибок там не было.

Проверено (норма, повтор, пустое состояние, ошибка, «Назад»):
- меню на компьютере и телефоне (2 раза подряд, Esc, после закрытия прокрутка свободна), все якоря, логотип;

- выбор квартиры: фасад → этаж (1, 5, 10) → квартира → 3D → планировка; шаги этажей до границ; Back/Forward закрывают и открывают квартиру; мышь и касание;

- окно квартиры: закрытие крестиком, Esc, кликом по фону; блокировка и разблокировка прокрутки; вперёд/назад; зум; PDF; кнопка «Оставить заявку» подставляет квартиру в форму;

- галерея: вперёд/назад, миниатюры, клавиатура, полноэкранный просмотр;

## Ограничения (что не проверялось или проверялось частично)

- **Safari (iOS и macOS) и Firefox не запускались.** В рабочей среде есть только Chromium; WebKit и Firefox для Playwright не установлены, а установить их нельзя (реестр пакетов закрыт). iPhone и Android проверены только эмуляцией в Chromium (размер, касания, DPR), а не на реальных устройствах. Нужна ручная проверка на iPhone (Safari) и Android (Chrome): safe-area, экранная клавиатура в форме, полноэкранный просмотр и свайп.
- Lighthouse CLI установить не удалось, поэтому использовался PageSpeed Insights (тот же Lighthouse 13.5.0, серверы Google) по живому сайту. API PageSpeed без ключа исчерпал квоту, поэтому замеры сняты через сайт PageSpeed Insights.
- Точный код редиректа (301 или 308) из браузера не виден: `fetch` следует редиректам. Конечные адреса проверены, тип указан по конфигурации Vercel.
- Экранные чтецы (VoiceOver, TalkBack) не проверялись; проверены роли, подписи и порядок фокуса.
- Поведение экранной клавиатуры в эмуляции не воспроизводится.
