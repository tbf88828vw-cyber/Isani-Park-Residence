# Отчёт о проверках — 29.09.2026

Проверки выполнены автоматически (Playwright, Chromium 141, headless) на локальном сервере, который отдаёт сборку `dist/` так же, как Vercel, и выполняет `api/lead.js`. Для проверки успешной отправки использовался тестовый Telegram-эндпоинт (реальные секреты не подключались). Скрипты: `tools/qa.mjs`, `tools/test-api.mjs`.

## Что проверено

**Вёрстка и адаптивность.** Все три языка × две темы × ширины 320, 375, 390, 768, 1024, 1440, 1920 px и альбомная 844×390: нет горизонтальной прокрутки, нет ошибок JavaScript (48 комбинаций). Текст 200% — без горизонтального переполнения. Ширина 320 px соответствует перекомпоновке при масштабе 400%.

**Отсутствие перезагрузок.** Смена темы, изменение размера окна, смена ориентации и масштаб страницы не перезагружают страницу: введённое имя и выбранные фильтры сохраняются (проверено маркером в `window`). Тема сохраняется между визитами.

**Смена языка.** Ссылка на другой язык сохраняет текущий раздел (`/en/#location`) и открытую квартиру (`/ka/#apt-N`); фильтры и черновик формы переносятся (sessionStorage).

**Сценарий покупателя (мобильный, 390 px).** Главный экран → фильтр «3 комнаты, 5 этаж» (6 квартир) → карточка № 88 → модальное окно с планом → кнопка «Назад» браузера закрывает окно → «Узнать цену и условия» → квартира подставляется в заявку → пустая отправка показывает ошибки → корректная отправка → сообщение «Заявка принята» только после ответа сервера `{ok:true}`. Текст сообщения, полученного тестовым Telegram, содержит имя, телефон, № квартиры, язык и источник перехода.

**Честные ошибки формы.** Если приём заявок не настроен (нет переменных окружения), пользователь видит «сервис приёма заявок недоступен», данные остаются в форме, событие `generate_lead` не отправляется. Двойной клик по кнопке отправляет одну заявку.

**Серверная функция.** Валидация имени/телефона/комментария; 405 на GET; 503 без настроенных каналов; 200 только при подтверждении доставки; 502 при сбое Telegram или сети; 422 при неверных данных; honeypot; ограничение частоты (429); белый список Origin (403); 400 на битый JSON.

**Доступность.** Один `h1` на странице; у всех изображений есть `alt` и размеры; у всех полей — подписи; у кнопок и ссылок есть доступные имена; интерактивные элементы ≥ 36 px (основные ≥ 44 px); масштабирование не запрещено. Клавиатура: первый Tab — ссылка «Перейти к содержанию»; фокус входит в модальное окно, остаётся в нём, Esc закрывает и возвращает фокус на карточку; видимый контур фокуса. Уважается `prefers-reduced-motion` (видео не запускается, анимации отключены, есть кнопка воспроизведения).

**Видео.** Воспроизводится без звука, `playsinline`, по кругу; кнопка паузы работает; при недоступном видео остаётся постер и все кнопки. Для браузеров без H.264 подключается WebM (VP9).

**Ссылки и файлы.** 325 внутренних адресов и изображений отвечают 200; для всех 218 квартир с планами есть изображение и PDF; страницы политики на трёх языках отвечают 200; несуществующий адрес отдаёт страницу 404.

**Аналитика.** События `select_apartment`, `form_start`, `generate_lead`, `click_phone`, `cta_click`, `map_open` попадают в `dataLayer`; проверено, что имя и телефон в `dataLayer` не попадают.

**Скорость (лабораторные данные).** Мобильная эмуляция (4× замедление CPU, 1,6 Мбит/с, 150 мс RTT), локальный сервер: LCP 1,2 с, CLS 0. Десктоп: LCP 0,26 с, CLS 0. Первый экран мобильной версии — около 1,2 МБ вместе с видео. Это лабораторные цифры без CDN и без веб-шрифтов; полевых данных (CrUX) у сайта пока нет.

## Что НЕ проверено

- **Safari / iPhone.** Движок WebKit в среде проверки недоступен. Вёрстка использует `svh/dvh`, `playsinline`, safe-area — но на реальном iPhone сайт нужно открыть перед запуском.
- **Настоящие шрифты.** Сеть среды проверки блокирует Google Fonts, поэтому скриншоты сняты с заменой шрифтов. Грузинская типографика (Noto Serif/Sans Georgian) визуально проверена не была — проверьте в браузере.
- **Реальная доставка заявок** в Telegram/почту — нужны токены (см. чек-лист запуска).
- **Карта Google** — встраивание не проверялось (нет доступа к Google из среды); ссылка «Открыть в Google Maps» формируется по адресу.
- **Проверка носителем языка.** Грузинские и английские тексты написаны без вычитки носителем. Рекомендуется вычитка перед запуском рекламы.
- **Автоматический аудит (axe/Lighthouse)** не запускался — пакеты недоступны в среде; выполнены ручные эквивалентные проверки, перечисленные выше.
- **Предпросмотр в Claude.** В предпросмотре-артефакте нет серверной функции, поэтому форма там честно показывает ошибку отправки; интерактивная карта там не загружается. Также в предпросмотре убраны AVIF-версии, малые превью планов и PDF-файлы (ограничение на количество файлов).
